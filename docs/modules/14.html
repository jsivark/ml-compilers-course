14Automatic differentiation

ML compilers differentiate programs as a graph transformation. You build forward and reverse mode yourself, then read how JAX implements grad as linearize plus transpose on a traced IR (Autodidax).

about 25–40 h · difficulty ●●●○○

After this module you can

  • Implement reverse-mode AD on a graph with gradient accumulation for nodes used more than once.
  • Derive VJPs and JVPs for core ops and check them against central finite differences in float64.
  • State the cost of forward vs reverse mode for f: R^n -> R and f: R -> R^n.
  • Explain how Autodidax implements jvp, vmap, jit and vjp as interpreters over a traced jaxpr.

Steps

Work through these in order. Each step points at one specific unit.

  1. Watch

    Karpathy: The spelled-out intro to neural networks and backpropagation: building micrograd

    Code along to build micrograd's scalar Value class with backward().

  2. Do

    micrograd repo: reproduce engine.py and pass the tests

    Re-implement engine.py from memory and check gradients against PyTorch as in test/test_engine.py.

  3. Do

    Autodiff Puzzles (Sasha Rush)

    Solve all puzzles: derive and implement backward for each tensor op, checked numerically.

  4. Read

    Baydin et al., Automatic Differentiation in Machine Learning: a Survey

    Read Section 2 (what AD is not) and Section 3 (forward mode with dual numbers, reverse mode). Skip Section 5, the survey of implementations.

  5. Do

    Implement forward mode with dual numbers

    Add a Dual class supporting + * sin exp, compute JVPs, and compare costs with your reverse-mode for R^n->R vs R->R^n functions.

  6. Read

    Autodidax Part 1: Transformations as interpreters (standard evaluation, jvp, vmap)

    Code along: primitives, the interpreter stack, and the JVP and vmap tracers.

  7. Do

    Autodidax Parts 2-3: Jaxprs and jit (simplified)

    Continue through make_jaxpr and the simplified jit that lowers jaxprs to XLA. This is tracing a Python function into an IR.

  8. Do

    Autodidax Part 4: linearize and vjp (and grad)

    Reverse mode as partial evaluation (linearize) followed by transposition. Implement grad in your mini system.

  9. Build

    Reverse-mode AD over your Module 13 DAG (read tinygrad mixin/gradient.py)

    Read tinygrad's gradient.py (a rewrite-rule-based gradient), then emit gradient graphs for your own IR.

Build

A Python tensor-free autodiff library with forward mode (dual numbers), reverse mode (tape/graph), and a tracing jit that records a jaxpr-like IR and computes grad as a transformation on that IR; validated against finite differences and PyTorch on 15 functions.

Portfolio project: Tensor autograd engine that trains a real model, with gradient-checkpointing

Extend scalar autograd to a NumPy-backed tensor library with broadcasting, reductions, matmul, softmax and cross-entropy, then train a small MLP or CNN on MNIST to a target accuracy. Add activation checkpointing and measure the memory/compute trade-off; add a forward-mode JVP and use it for a Hessian-vector product.

Deliverables

  • repo with tensor autograd, 20+ ops each with a finite-difference gradient test, and an MNIST training script
  • README with accuracy curves, peak-memory vs recompute plots for checkpointing, and HVP verification results
  • a 600–1200 word write-up explaining reverse vs forward mode, broadcasting gradients, and the checkpointing trade-off

Rubric

Solid
All op gradients pass finite-difference checks (rtol 1e-5 in float64); MNIST MLP reaches 97%+ test accuracy.
Exceptional
Checkpointing cuts peak memory by a measured factor with sqrt(n) segment analysis, HVP via forward-over-reverse verified, and results matched against PyTorch to 1e-6.

References: micrograd, Autodidax: JAX core from scratch

If you get stuck

  • Broadcast inputs need their gradient summed back to the input shape; most backward shape errors come from this.
  • Run backward in reverse topological order, or a node's gradient is read before all contributions arrive.
  • A node used twice must accumulate its gradient (+=), not overwrite it.
  • Use float64 for gradient checks; float32 finite differences produce false failures.
  • If Autodidax Part 4 is hard to follow, finish the dual-number step first.

Ready to move on when

  • Gradients agree with central finite differences to 1e-5 on all test functions
  • You can explain why reverse mode costs O(1) passes for scalar loss and forward mode O(n)
  • Your traced IR for a 2-layer MLP prints readable and its grad IR runs correctly
  • Higher-order: grad(grad(f)) works for f=x**3

Going deeper (optional)

  • MIT 18.S096 Matrix Calculus for ML — Rigorous Jacobian/adjoint view.
  • The Simple Essence of Automatic Differentiation (Elliott) — Category-theory view of AD as compositional.
