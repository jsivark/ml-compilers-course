33CUTLASS, CuTe and Hopper/Blackwell features

The fastest H100/B200 kernels (FlashAttention-3, cuBLAS-class GEMMs) use TMA, wgmma and warp specialization. CUTLASS and its CuTe layout library expose these directly; Triton exposes them only partly.

about 55–85 h · difficulty ●●●●●

After this module you can

  • Compute CuTe layout composition and logical_divide by hand and check with cute::print.
  • Build a TMA+wgmma pipelined GEMM on Hopper and measure it against cuBLAS.

Steps

Work through these in order. Each step points at one specific unit.

  1. Read

    Simon Boehm, How to Optimize a CUDA Matmul Kernel

    Warm-up: the article covers kernels 1-6, 9 (autotuning) and 10 (warptiling); it skips 7 and 8 in the text. Re-derive them for the vocabulary used below.

  2. Read

    CuTe quickstart (CUTLASS docs)

    Then read 01_layout.md, 02_layout_algebra.md, 03_tensor.md and 0x_gemm_tutorial.md in the same folder; 0z_tma_tensors.md before the Hopper GEMM.

  3. Practice

    CuTe docs folder: layout algebra exercises

    Hand-compute composition, complement and logical_divide on 2-3 layouts; check with cute::print.

  4. Read

    Colfax: CUTLASS Tutorial: Efficient GEMM kernel designs with Pipelining

    Software pipelining of the mainloop with mbarriers, and warp-specialized producer/consumer designs.

  5. Read

    Colfax: CUTLASS Tutorial: Mastering the NVIDIA Tensor Memory Accelerator (TMA)

    TMA load and store, TMA store reduce, TMA load multicast, and the PTX they map to.

  6. Read

    Colfax: CUTLASS Tutorial: Fast Matrix-Multiplication with WGMMA on NVIDIA Hopper GPUs

    Warpgroup MMA, smem layout requirements, and wgmma.fence / commit_group / wait_group (cute::warpgroup_arrive, commit_batch, wait).

  7. Read

    PTX ISA: wgmma and cp.async.bulk sections

    Look up wgmma.mma_async and cp.async.bulk.tensor; see exactly what CuTe emits.

  8. Read

    FlashAttention-3

    Section 3.1: producer-consumer warp specialization and pingpong scheduling; 3.2: overlapping GEMM and softmax inside a warpgroup; 3.3: FP8, including incoherent processing.

  9. Read

    ThunderKittens: Simple, Fast, and Adorable AI Kernels

    Tile primitives between Triton and CUTLASS in abstraction level. Compare with what you wrote in module 32.

  10. Implement

    ThunderKittens: run the educational H100 GEMM series

    Build kernels/gemm/educational_h100 step by step; profile each step with Nsight Compute and name what changed.

  11. Implement

    Write a Hopper GEMM in CuTe

    TMA load -> smem -> wgmma, 2-4 stage pipeline, then add warp specialization. No GPU with sm90? Rent one by the hour.

Build

A from-scratch CuTe GEMM for H100 progressing from SIMT to wgmma+TMA+warp-specialized, each step benchmarked.

Portfolio project: bf16 MoE grouped GEMM on Hopper with a public benchmark

Implement a warp-specialized Hopper grouped GEMM for MoE layers in bf16, using the expert shapes from Mixtral 8x7B (hidden 4096, FFN 14336, 8 experts, top-2) at token counts 128, 512 and 4096. Benchmark against a loop of cuBLAS GEMMs and document each optimization with Nsight Compute evidence.

Deliverables

  • repo with the kernel, a PyTorch extension binding and correctness tests
  • README with TFLOPS tables vs. baselines across >=6 shapes
  • a 600–1200 word write-up walking through the pipeline, layouts and the remaining gap

Rubric

Solid
>=60% of the best public baseline on all shapes, correct to fp tolerance, profiler screenshots
Exceptional
Beats the cuBLAS loop on small token counts and explains why with occupancy and pipeline analysis.

References: FlashAttention-3, ThunderKittens

If you get stuck

  • Template error walls: compile tiny examples first and use cute::print/print_latex to inspect layouts
  • wgmma hangs or garbage: missing fence/commit/wait or wrong smem swizzle; compare with the Colfax wgmma post line by line
  • No Hopper GPU: do the layout and SIMT parts locally, then rent an H100 for a few hours with a script ready
  • TMA descriptor errors: global tensor must be 16-byte aligned and strides multiples of 16 bytes
  • Lost in CUTLASS 3 collectives: read the Colfax pipelining post before the source

Ready to move on when

  • Final GEMM reaches >=70% of cuBLAS bf16 at 8192^2 on H100
  • You can draw the CuTe layout (shape:stride) of an smem tile with swizzle
  • You can explain why warp specialization helps when TMA is async
  • Nsight Compute report shows tensor-core utilization per version
