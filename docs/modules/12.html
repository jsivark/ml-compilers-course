Part II · Bridge

12IRs, SSA and optimization passes

Real compilers optimize on an intermediate representation, not the AST. CS6120 (Fall 2020, with a self-guided version) uses the Bril IR to teach control-flow graphs, dataflow analysis and SSA through small implementation tasks.

about 40–55 h (6 lessons with tasks at 5-8 h each, plus the mycc IR stage) · difficulty ●●●●○

StepsBuildProjectHelpGo deeper

After this module you can

  • Build a CFG from Bril and convert it into and out of SSA using dominance frontiers.
  • Implement a worklist dataflow solver and instantiate it for at least two analyses.
  • Implement TDCE, LVN and LICM and measure their effect with dynamic instruction counts.

Steps

Work through these in order. Each step points at one specific unit.

  1. Watch

    CS6120 Lesson 1: Welcome & Overview

    Read the lesson and the self-guided page (cs6120/2020fa/self-guided/), which explains how to do the course without enrollment.

  2. Do

    CS6120 Lesson 2: Representing Programs -- video + task

    Install bril2json and brili. Do the task: write a Bril benchmark, and write a small tool that loads Bril JSON (for example, counts add instructions). Then form basic blocks and a CFG as the lesson derives.

  3. Do

    CS6120 Lesson 3: Local Analysis & Optimization -- video + task

    Implement trivial dead code elimination (iterate to convergence) and local value numbering. Compare dynamic instruction counts with 'brili -p' on the benchmarks.

  4. Do

    CS6120 Lesson 4: Data Flow -- video + task

    The task asks for at least one dataflow analysis; do the bonus generic worklist solver and instantiate it for reaching definitions and live variables.

  5. Do

    CS6120 Lesson 5: Global Analysis & SSA -- video + task part 1 (dominators)

    Find dominators, build the dominator tree and compute dominance frontiers; test against brute-force path enumeration.

  6. Do

    CS6120 Lesson 5 task part 2: into and out of SSA

    Implement into-SSA and out-of-SSA. Check SSA form with the lesson's is_ssa.py and run the midpoint under brili, which supports phi. Watch for variables undefined on some paths.

  7. Watch

    CS6120 Lesson 6: LLVM -- video + task

    The task: follow the LLVM for Grad Students tutorial far enough to write a pass that changes program execution (for example, print on every floating-point division). Requires C++ and an LLVM install; optional.

  8. Do

    CS6120 Lesson 7: Loop Optimization -- video + task

    Implement natural loop detection and LICM on Bril (the lesson's recommended choice) and evaluate it on the Bril benchmarks.

  9. Watch

    CS6120 Lesson 11: Dynamic Compilers

    Watch the lecture. The task is a trace-based speculative optimizer for Bril: modify brili to record a trace and reinject it with the speculation extension. Lessons 8-10 are optional.

  10. Build

    Lower your Module 11 compiler through a Bril-like IR

    Read the Bril language reference, then add a three-address IR stage to mycc from Module 11 and run your TDCE/LVN passes before codegen.

Build

A Python optimizer for Bril with CFG construction, a worklist dataflow solver, dominators, into/out of SSA, TDCE+LVN and LICM; a script runs bril/benchmarks/core before and after and reports dynamic instruction counts from 'brili -p' with output checks.

Portfolio project: mycc, stage 2: An optimizing middle-end with a measured pass pipeline

Skill project

Build an SSA middle-end on Bril with SCCP, GVN (the lesson 5 bonus), LICM and aggressive DCE, then study pass ordering. Report dynamic instruction counts from 'brili -p' on bril/benchmarks/core and check brili output equivalence after every pass.

Deliverables

  • repo with IR, SSA construction/destruction, 4+ optimization passes and a pass manager
  • README with a table of dynamic instruction counts per benchmark per pass and a pass-ordering heatmap
  • a 600–1200 word write-up explaining SSA construction, why SCCP beats separate const-prop + DCE, and one miscompile you found

Rubric

Solid
All passes preserve output on every core benchmark; the full pipeline lowers dynamic instruction count on at least half the benchmarks and raises it on none.
Exceptional
An exhaustive search over orders of the 4 passes with the best order per benchmark reported, and a random-program fuzzer that found and fixed at least one miscompile.

References: Cornell CS 6120 Fall 2020 self-guided, Simple and Efficient Construction of SSA Form (Braun et al.)

Help

If you get stuck

  • Phi placement errors usually come from a wrong dominator tree: test dominators alone on hand-drawn CFGs first.
  • Out-of-SSA with naive sequential copies hits the lost-copy and swap problems; the lesson links Boissinot et al. on correct translation.
  • A non-terminating dataflow solver means a transfer function that is not monotone (lesson 4 theory section).
  • Run each pass alone and check brili output against the unoptimized program before combining passes.

Ready to move on when

  • Every program in bril/benchmarks/core prints the same output before and after your passes
  • LVN on 'a = add x y; b = add y x' reuses a (requires the commutativity extension)
  • is_ssa.py accepts your into-SSA output, and SSA round-trips give identical brili output
  • Your dominator tree for a hand-drawn nested-loop CFG matches a by-hand answer

Go deeper (optional)

Talks, papers, code and writing (16)

Courses

  • Kaleidoscope: Implementing a Language with LLVM · LLVM project
    Builds a small language on LLVM IR with its pass manager and JIT; chapter 4 is a practical companion to Lesson 6.
  • CS6120 self-guided (Fall 2023) · Adrian Sampson
    The later revision of the course with updated lessons and videos; use it for topics after lesson 11 such as alias analysis and GC.

Papers

  • A Simple, Fast Dominance Algorithm · Keith Cooper, Timothy Harvey, Ken Kennedy
    The iterative dominator algorithm most compilers use; implement its intersect routine and compare to your set-based version.
  • Efficiently Computing Static Single Assignment Form and the Control Dependence Graph · Cytron, Ferrante, Rosen, Wegman, Zadeck
    The classic SSA construction via dominance frontiers; sections 4-5 are the algorithm you implement in lesson 5.
  • LLVM: A Compilation Framework for Lifelong Program Analysis and Transformation · Chris Lattner, Vikram Adve
    The CGO 2004 paper defining LLVM's typed SSA IR; read section 2 on the IR design.
  • MLIR: A Compiler Infrastructure for the End of Moore's Law · Chris Lattner et al.
    How SSA-based IR generalizes to dialects for ML compilers; read sections 2-4 to connect Bril to the later Parts.

Books

  • Static Program Analysis · Anders Moller, Michael Schwartzbach
    Free lattice-based treatment of dataflow; chapters 4-5 give the monotone framework behind your worklist solver.
  • LLVM (The Architecture of Open Source Applications) · Chris Lattner
    Lattner's account of LLVM IR and the pass pipeline design; focus on the sections on IR as the complete interface.

Blogs and articles

  • Land ahoy: leaving the Sea of Nodes · V8 team
    Why V8 replaced its Sea of Nodes IR with a CFG-based IR (Turboshaft); a rare production postmortem on IR design to read against the Simple/Sea of Nodes material.
  • The acyclic e-graph: Cranelift's mid-end optimizer · Chris Fallin
    A 2026 deep dive on how Cranelift folded GVN, LICM, constant folding and rematerialization into one e-graph pass to escape pass ordering; read the pass-ordering motivation first.
  • A catalog of ways to generate SSA · Max Bernstein
    A history of SSA construction algorithms from Cytron to Braun et al., with how the author builds SSA in practice; read before your SSA conversion.
  • What I talk about when I talk about IRs · Max Bernstein
    Practical criteria for designing an IR; compare them with the UOp graph you will build in Module 18.

Code to read

  • Simple (Sea of Nodes tutorial) · Cliff Click and contributors
    A chaptered compiler built on the Sea of Nodes IR used in HotSpot C2 and V8; read chapters 1-10 to see an IR where SSA and scheduling merge.

More reading

  • Engineering a Compiler (Cooper & Torczon) ch. 8-9 — 3rd edition: ch. 8 Introduction to Optimization, ch. 9 Data-Flow Analysis.
  • SSA Book (Static Single Assignment Book) — Free reference on SSA construction and destruction.
  • Simple and Efficient Construction of SSA Form (Braun et al.) — Alternative SSA construction used in many modern compilers.
Stretch project

Implement SCCP, GVN-PRE (or GVN plus LICM) and Briggs-style out-of-SSA with parallel-copy sequentialization on Bril, then run a pass-ordering study: try all orderings of 4 passes over bril/benchmarks and report the best and worst dynamic instruction counts per benchmark. Explain at least two cases where order changes the result by more than 5%.
