15Deep learning systems

Before compiling tensor programs you need a tensor library: strides, broadcasting, autograd on tensors, and fast kernels. MiniTorch and CMU DLSys (10-414/714) build each piece with tests.

about 55–80 h · difficulty ●●●●○

After this module you can

  • Implement strided views (reshape, permute, expand) that share storage with the original tensor.
  • Implement tensor broadcasting and tensor-level autograd that pass the MiniTorch Module 2 tests.
  • Write a tiled CPU matmul and a CUDA matmul for an NDArray backend.
  • Train LeNet on MNIST with your own framework.

Steps

Work through these in order. Each step points at one specific unit.

  1. Do

    MiniTorch Module 0: Fundamentals, Tasks 0.1-0.5

    Operators, Testing and Debugging (hypothesis), Functional Python, Modules, Visualization. Set up the repo and get the test harness green.

  2. Do

    MiniTorch Module 1: Autodiff, Tasks 1.1-1.5

    Numerical derivatives, scalars, chain rule, backpropagation, training. Compare with your Module 14 code.

  3. Do

    MiniTorch Module 2: Tensors, Tasks 2.1-2.5

    2.1 Tensor Data - Indexing, 2.2 Tensor Broadcasting, 2.3 Tensor Operations, 2.4 Gradients and Autograd, 2.5 Training. Strides here are the same idea as tinygrad's views.

  4. Do

    MiniTorch Module 3: Efficiency, Tasks 3.1-3.5

    3.1 Parallelization (Numba), 3.2 Matrix Multiplication, 3.3 CUDA Operations, 3.4 CUDA Matrix Multiplication, 3.5 Training. Time the naive and parallel versions.

  5. Do

    MiniTorch Module 4: Networks, Tasks 4.1-4.5

    4.1 1D Convolution, 4.2 2D Convolution, 4.3 Pooling, 4.4 Softmax and Dropout, 4.5 Training an Image Classifier (LeNet on MNIST).

  6. Watch

    CMU DLSys Lectures 3-5: Manual Neural Networks / Backprop, Automatic Differentiation, Automatic Differentiation Implementation

    Compare needle's computational-graph design with MiniTorch's.

  7. Do

    DLSys Homework 1: needle autodiff

    Implement forward and backward for needle ops and reverse-mode AD with a topological sort (hw1.ipynb).

  8. Watch

    DLSys Lectures 10, 12, 13: Hardware Acceleration for Linear Algebra, Hardware Acceleration + GPUs, Hardware Acceleration Implementation

    Focus on the strided NDArray backend design and tiling.

  9. Do

    DLSys Homework 3: NDArray backend (CPU + CUDA)

    Implement compact/setitem, elementwise ops, reductions and tiled matmul in C++ and CUDA (hw3.ipynb).

Build

A tinygrad-like tensor library in Python: strided Tensor with views (reshape/permute/expand without copy), broadcasting, reverse-mode autograd, a CPU backend in C via ctypes with tiled matmul, and an MNIST MLP training to >97% accuracy.

Portfolio project: Lazy-evaluating mini-framework with fusion and a benchmark against PyTorch CPU

Make your framework lazy: build an op graph, fuse elementwise chains and their following reduction into single generated C kernels, and reuse buffers. Train a 2-layer, 128-dim character-level transformer on Tiny Shakespeare (about 1 MB of text) for 2000 steps and compare speed and memory against your eager mode and PyTorch CPU.

Deliverables

  • repo with lazy graph, fusion pass, codegen backend, memory planner, and a char-level transformer training script
  • README with kernel-count, peak-memory and tokens/sec comparisons (eager vs fused vs PyTorch CPU) and loss curves
  • a 600–1200 word write-up explaining the fusion rules, where fusion is illegal, and the memory planner design

Rubric

Solid
Fused mode launches at least 3x fewer kernels than eager, matches eager outputs to 1e-5, and validation loss falls below 2.0 nats/char.
Exceptional
Within 2x of PyTorch CPU tokens/sec, a liveness-based memory planner with measured savings, and a visualization of the scheduled graph.

References: CMU 10-414/714 Deep Learning Systems, tinygrad

If you get stuck

  • Stride bugs: compare your view ops to NumPy on random shapes before building on them.
  • Non-contiguous tensors break naive kernels; decide where you call compact()/contiguous() and test both paths.
  • Softmax and log-softmax overflow unless you subtract the row max.
  • If training does not learn, overfit a single batch first; failure there means a gradient bug.

Ready to move on when

  • permute/expand/reshape produce views (no data copy) verified by shared storage
  • All MiniTorch Module 2 tests pass
  • Your tiled matmul is at least 5x faster than the naive triple loop at 1024x1024
  • MNIST trains to >97% test accuracy with your library

Going deeper (optional)

  • tinygrad source: tensor.py — Compare your Tensor API with the real thing.
  • DLSys Homework 4 (CNNs, RNNs) — Further model work on your backend.
