Part II · Bridge

15Automatic differentiation

ML compilers differentiate programs as a graph transformation. You build forward and reverse mode yourself, then read how JAX implements grad as linearize plus transpose on a traced IR (Autodidax).

about 25–40 h · difficulty ●●●○○

StepsBuildProjectHelpGo deeper

After this module you can

  • Implement reverse-mode AD on a graph with gradient accumulation for nodes used more than once.
  • Derive VJPs and JVPs for core ops and check them against central finite differences in float64.
  • State the cost of forward vs reverse mode for f: R^n -> R and f: R -> R^n.
  • Explain how Autodidax implements jvp, vmap, jit and vjp as interpreters over a traced jaxpr.

Steps

Work through these in order. Each step points at one specific unit.

  1. Watch

    Karpathy: The spelled-out intro to neural networks and backpropagation: building micrograd

    Code along to build micrograd's scalar Value class with backward().

  2. Do

    micrograd repo: reproduce engine.py and pass the tests

    Re-implement engine.py from memory and check gradients against PyTorch as in test/test_engine.py.

  3. Do

    Autodiff Puzzles (Sasha Rush)

    Solve all puzzles: derive and implement backward for each tensor op, checked numerically.

  4. Read

    Baydin et al., Automatic Differentiation in Machine Learning: a Survey

    Read Section 2 (what AD is not) and Section 3 (forward mode with dual numbers, reverse mode). Skip Section 5, the survey of implementations.

  5. Do

    Implement forward mode with dual numbers

    Add a Dual class supporting + * sin exp, compute JVPs, and compare costs with your reverse-mode for R^n->R vs R->R^n functions.

  6. Read

    Autodidax Part 1: Transformations as interpreters (standard evaluation, jvp, vmap)

    Code along: primitives, the interpreter stack, and the JVP and vmap tracers.

  7. Do

    Autodidax Parts 2-3: Jaxprs and jit (simplified)

    Continue through make_jaxpr and the simplified jit that lowers jaxprs to XLA. This is tracing a Python function into an IR.

  8. Do

    Autodidax Part 4: linearize and vjp (and grad)

    Reverse mode as partial evaluation (linearize) followed by transposition. Implement grad in your mini system.

  9. Build

    Reverse-mode AD over your Module 14 DAG (read tinygrad mixin/gradient.py)

    Read tinygrad's gradient.py (a rewrite-rule-based gradient), then emit gradient graphs for your own IR.

Build

A Python tensor-free autodiff library with forward mode (dual numbers), reverse mode (tape/graph), and a tracing jit that records a jaxpr-like IR and computes grad as a transformation on that IR; validated against finite differences and PyTorch on 15 functions.

Portfolio project: kiln v0.7: gradients as a graph transformation, with checkpointing

kiln, the main project · v0.7 adds gradients built as a graph transformation, plus checkpointing · builds on v0.6 · next: v0.8

Change kiln so the backward pass is built as more graph IR instead of run from a tape. Then the v0.6 rewrite engine and your passes can optimize forward and backward together. Cover broadcasting, reductions, matmul, softmax and cross-entropy, and train an MLP on MNIST through the graph path. Add activation checkpointing as a graph pass and measure the memory and compute trade-off, then compose forward and reverse mode for a Hessian-vector product.

Deliverables

  • kiln v0.7 tagged: graph-built backward pass, 20+ ops each with a finite-difference gradient test, and an MNIST training script
  • README with accuracy curves, peak-memory vs recompute plots for checkpointing, and HVP verification results
  • a 600–1200 word write-up explaining reverse vs forward mode, broadcasting gradients, and the checkpointing trade-off

Rubric

Solid
All op gradients pass finite-difference checks (rtol 1e-5 in float64); MNIST MLP reaches 97%+ test accuracy.
Exceptional
Checkpointing cuts peak memory by a measured factor with sqrt(n) segment analysis, HVP via forward-over-reverse verified, and results matched against PyTorch to 1e-6.

References: micrograd, Autodidax: JAX core from scratch

Help

If you get stuck

  • Broadcast inputs need their gradient summed back to the input shape; most backward shape errors come from this.
  • Run backward in reverse topological order, or a node's gradient is read before all contributions arrive.
  • A node used twice must accumulate its gradient (+=), not overwrite it.
  • Use float64 for gradient checks; float32 finite differences produce false failures.
  • If Autodidax Part 4 is hard to follow, finish the dual-number step first.

Ready to move on when

  • Gradients agree with central finite differences to 1e-5 on all test functions
  • You can explain why reverse mode costs O(1) passes for scalar loss and forward mode O(n)
  • Your traced IR for a 2-layer MLP prints readable and its grad IR runs correctly
  • Higher-order: grad(grad(f)) works for f=x**3
Reference implementations (4)

Make a real attempt first. When you are stuck, or after you finish, compare your work with these.

  • Autodidax source (autodidax.py in the JAX repo) (Autodidax Parts 1-4 and the tracing-jit part of the build)
    The complete runnable source behind the Autodidax tutorial, including the jvp, vmap, jit, linearize and vjp interpreters.
  • nn-zero-to-hero: micrograd lecture notebooks (Karpathy) (micrograd video and engine.py reimplementation)
    The notebooks Karpathy wrote live in the micrograd video, so you can diff your Value class and backward() against his at each stage.
  • HIPS/autograd (Build (forward and reverse mode) and the tensor autograd project)
    A compact, production-quality NumPy autodiff library with reverse mode, forward mode and VJP definitions for hundreds of NumPy ops, including broadcasting unbroadcast logic.
  • tinygrad engine/realize.py and codegen/memory.py at the pinned commit (Reverse-mode AD over your Module 14 DAG)
    Shows how tinygrad runs the scheduled forward and gradient graphs; read it after mixin/gradient.py to see where your gradient graph gets executed.

Lectures

  • CSC421 Lecture 6 reading: Automatic Differentiation · Roger Grosse (University of Toronto)
    Concise notes that build a simplified version of HIPS Autograd step by step; good companion while doing the module's from-scratch engine.
  • L46 Principles of ML Systems: Automatic Differentiation slides · University of Cambridge
    Systems-flavoured slides from a 2023-24 ML systems course, linking AD modes to how frameworks implement them.

Courses

  • JAX: The Autodiff Cookbook · JAX authors
    Hessian-vector products via forward-over-reverse, jacfwd vs jacrev costs; use it to check your HVP.

Papers

  • Training Deep Nets with Sublinear Memory Cost · Tianqi Chen, Bing Xu, Chiyuan Zhang, Carlos Guestrin
    The sqrt(n) activation-checkpointing analysis your project asks for; focus on Section 3 and the memory-planning algorithm.
  • You Only Linearize Once: Tangents Transpose to Gradients · Alexey Radul, Adam Paszke, Roy Frostig, Matthew Johnson, Dougal Maclaurin
    The formal account of JAX's linearize-then-transpose design that Autodidax Part 4 implements; read the linear type system section.
  • Instead of Rewriting Foreign Code for Machine Learning, Automatically Synthesize Fast Gradients (Enzyme) · William Moses, Valentin Churavy
    AD as an LLVM compiler pass, showing why differentiating after optimization is faster; read the motivation and Section 3.
  • Don't Unroll Adjoint: Differentiating SSA-Form Programs (Zygote) · Michael Innes
    Source-to-source reverse mode on an SSA compiler IR with control flow, the alternative to tracing that your jit uses.
  • Compiling machine learning programs via high-level tracing (JAX, SysML 2018) · Roy Frostig, Matthew Johnson, Chris Leary
    The original 4-page JAX paper: tracing to an IR, then composing grad and jit as transformations.

Books

  • The Elements of Differentiable Programming · Mathieu Blondel, Vincent Roulet
    A modern textbook treatment of JVPs, VJPs, checkpointing and second-order AD; chapters 7-9 cover autodiff in depth.
  • Evaluating Derivatives (2nd ed.) · Andreas Griewank, Andrea Walther
    The reference text on AD theory; chapter 12 on checkpointing (revolve) is the source of optimal recompute schedules.

Blogs and articles

  • Calculus on Computational Graphs: Backpropagation · Chris Olah
    The clearest picture of why reverse mode wins for many-inputs-one-output; read the forward vs reverse diagrams.
  • Yes you should understand backprop · Andrej Karpathy
    Concrete gradient failure modes (vanishing sigmoid, dead ReLU, exploding RNN) that a working AD engine can still produce.
  • Autograd mechanics · PyTorch
    How a production tape handles saved tensors, in-place ops and version counters; compare with your tape design.
  • Reverse mode automatic differentiation · Eli Bendersky
    A 2025 write-up that treats reverse mode as a generalization of backprop, working through a small Python implementation; focus on how the tape is built and replayed.
  • Overview of PyTorch Autograd Engine · PyTorch team
    Part 1 of the official three-part autograd series; read the Jacobian-vector product section and how the backward graph is recorded during the forward pass.
  • How Computational Graphs are Constructed in PyTorch · PyTorch team
    Part 2 walks through grad_fn nodes, SavedVariable and the codegen behind derivatives.yaml; compare the design with your own micrograd-style engine.
  • How Computational Graphs are Executed in PyTorch · PyTorch team
    Part 3 covers the C++ engine: dependency counting, the ready queue and per-device worker threads; focus on how topological order is computed at runtime.
  • How to read the autograd codebase · PyTorch dev-discuss forum
    A map from Python API to the C++ files that implement autograd; use it as a guide before reading torch/csrc/autograd.

Code to read

    The working LLVM/MLIR AD plugin from the paper; browse the test cases to see gradients of real C loops.
