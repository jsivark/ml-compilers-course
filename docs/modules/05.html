Part I · Foundations

05Linear algebra

Tensors are the data and matmul is the main workload. You need matrices both as transformations and as computations (elimination and factorization).

about 25–40 h · difficulty ●●○○○

StepsBuildProjectHelpGo deeper

After this module you can

  • Compute a matmul four ways (row, column, outer product, block) and say which access pattern each uses.
  • Implement LU with partial pivoting and use it to solve Ax=b.
  • State the rank, null space dimension and determinant meaning for a given small matrix.
  • Measure relative error against NumPy and show a case where pivoting changes it.

Steps

Work through these in order. Each step points at one specific unit.

  1. Watch

    3Blue1Brown, Essence of Linear Algebra ch. 1-4: vectors, linear transformations, matrix multiplication

    Also watch the span and matrix-multiplication lessons. Goal: read a matrix's columns as where the basis vectors land.

  2. Watch

    3Blue1Brown ch. 6-7: determinants, inverses, column space and null space

    Then watch the inverse matrices lesson.

  3. Watch

    3Blue1Brown ch. 9, 13-14: dot products, change of basis, eigenvectors

    Then the change of basis and eigenvectors lessons. Skip cross products.

  4. Watch

    MIT 18.06 lecture 1: the geometry of linear equations

    Watch the lecture, then do the session's problem set and check against the solutions.

  5. Watch

    MIT 18.06 lectures 2-3: elimination, matrix multiplication and inverses

    Then multiplication-and-inverse-matrices/. Lecture 3 covers four ways to multiply matrices (row, column, columns times rows, blocks), which map to different kernel loop orders.

  6. Watch

    MIT 18.06 lecture 4: LU factorization

    Count the operations and confirm elimination costs about n^3/3 multiply-adds.

  7. Watch

    MIT 18.06 lecture 5: transposes, permutations, vector spaces

    Permutation matrices reappear as tensor permute in Module 7.

  8. Watch

    MIT 18.06 lectures 6 and 10: column space, nullspace and the four subspaces

    Then the-four-fundamental-subspaces/. Do both problem sets.

  9. Read

    Inside the Matrix: visualizing matrix multiplication (PyTorch blog)

    Read sections 2 and 3 (dot product, matrix-vector, summed outer products, expressions). Leave section 4 onward (attention) for Module 10.

  10. Build

    Write a small linear algebra library in pure Python

    Implement it as specified in build; use numpy.linalg only as the oracle in tests.

Build

Pure-Python (lists only) matmul, transpose, LU decomposition with partial pivoting, forward/back substitution and solve(A,b). Test against numpy on 100 random matrices to 1e-9, and include a 4-ways-of-matmul file (row, column, outer-product, block) that all agree.

Project

No separate project here. The numerical-stability work moves into the Module 6 project (kiln v0.2), and blocking is covered properly by the Module 17 matmul worklog. Do this module's Build to practise the linear algebra. Go to Module 06.

Help

If you get stuck

  • The 3Blue1Brown videos give intuition, not fluency. Work the 18.06SC problem sets by hand.
  • LU without pivoting fails on a zero (or tiny) pivot; test on [[1e-20,1],[1,1]] to see catastrophic error, then add pivoting.
  • Comparing floats with == in tests: use a relative tolerance (numpy.allclose semantics).
  • Mixing up row-major indexing A[i][j] with the column picture of Ax: write out a 2x2 example both ways (18.06 Lecture 1).

Ready to move on when

  • Explain matrix multiplication as composition of transformations, and as a sum of outer products.
  • Explain what the determinant means geometrically and why det=0 means no inverse.
  • Perform LU by hand on a 3x3 and verify L*U=A.
  • State the dimensions of the four fundamental subspaces of an m x n matrix of rank r.
  • Count the flops of an n x n matmul and of LU.
Reference implementations (4)

Make a real attempt first. When you are stuck, or after you finish, compare your work with these.

  • Reference LAPACK LU code (dgetrf2.f) (Build: LU with partial pivoting)
    The reference recursive LU with partial pivoting; compare its pivot search and row swaps with your pure-Python version.
  • fast.ai numerical linear algebra notebooks (Build and Project: LU and blocked algorithms)
    Rachel Thomas's notebooks with worked NumPy code for LU, pivoting, stability and blocked algorithms.
  • MIT 18.06 course notebooks (18.06 problem sets)
    MIT 18.06 course repo with Julia notebooks and problem-set solutions on elimination, LU and the four subspaces.
  • How to optimize GEMM: step-by-step matrix multiply tuning (Project: blocked matmul)
    Shows blocked matmul built up in steps; the blocking structure transfers directly to the NumPy tiled version.

Go deeper (optional)

Talks, papers, code and writing (14)

Courses

  • Introduction to Applied Linear Algebra (VMLS) · Stephen Boyd and Lieven Vandenberghe
    Free book focused on computation and least squares; read chapters 10-12 on matrix multiplication, inverses and least squares.
  • Matrix Calculus for Machine Learning and Beyond (MIT course) · Alan Edelman and Steven G. Johnson
    The derivatives of matrix functions you need for autodiff in Part II; watch lectures 1-4.
  • Cornell CS 4220: numerical analysis course · David Bindel
    Bindel's lecture notes on LU, conditioning and backward error; read the linear systems weeks for the project's stability analysis.
  • MIT 18.065: matrix methods for data and machine learning (Gilbert Strang) · Gilbert Strang (MIT OCW)
    Lecture videos and problem sets that go from SVD and low-rank approximation to backprop and convolution; watch the SVD and low-rank lectures first.
  • Cornell CS 6210: matrix computations course · David Bindel (Cornell)
    Current notes and slides on floating point, blocking, LU/QR and conditioning; the early floating-point and performance lectures cover bf16 and why blocked algorithms matter.
  • Berkeley Math 221: numerical linear algebra course · James Demmel (UC Berkeley)
    Full lecture notes from the author of Applied Numerical Linear Algebra; Lecture 2 on roundoff and low precision for ML is the most relevant part.

Papers

  • Anatomy of High-Performance Matrix Multiplication · Kazushige Goto and Robert van de Geijn
    Shows how block matrix multiplication becomes a hardware schedule; sections 2-3 connect Lecture 3's block view to real kernels.

Books

  • Linear Algebra Done Right (free PDF) · Sheldon Axler
    The proof-based view of linear maps; read chapter 3 for the abstract picture behind 3Blue1Brown.
  • Immersive Linear Algebra · J. Strom, K. Astrom, T. Akenine-Moller
    Interactive figures for every concept; useful when a 2-D picture of a transform does not click.
  • How to Scale Your Model, Part 3: Sharded Matrices · Google DeepMind (Austin et al.)
    Block matrix multiplication split across devices; read it after the blocked-matmul project to see the same algebra at cluster scale.

Blogs and articles

  • Understanding NumPy's einsum · Eli Bendersky
    Shows how an einsum string maps to explicit nested loops; that loop view is exactly how tensor contractions are lowered in later compiler modules.

More reading

  • Mathematics for Machine Learning, ch. 2-4 — More formal treatment.
  • MIT 18.06 unit II: least squares, determinants, eigenvalues — Continue if you enjoy it.
  • 3Blue1Brown: Abstract vector spaces — Final chapter of the series.
Stretch project

Implement communication-avoiding (tournament pivoting) LU or recursive LU in NumPy and compare its backward error and runtime against partial-pivoting LU across condition numbers 1 to 1e12 and N up to 4096. Reproduce the growth-factor example where partial pivoting fails (Wilkinson's matrix) and report growth factors for each method.
