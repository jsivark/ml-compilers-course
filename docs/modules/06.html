06Tensors, broadcasting, strides

A tensor is a pointer, a shape and strides. Reshape, permute and expand are pure index arithmetic, which is exactly what you will compile in Module 22.

about 30–45 h · difficulty ●●●○○

StepsBuildProjectHelpGo deeper

After this module you can

  • After this module you can compute strides and offsets for any slice, transpose or expand and predict when an operation copies.
  • After this module you can implement broadcasting from its rules.
  • After this module you can replace Python loops with array operations using only broadcasting and indexing.
  • After this module you can explain how PyTorch separates a tensor's storage from its view metadata.

Steps

Work through these in order. Each step points at one specific unit.

  1. Read

    Rougier, From Python to NumPy, chapter "Anatomy of an array"

    Sections: memory layout, views and copies. Run every snippet.

  2. Read

    Alex Riley (ajcr), An Illustrated Guide to Shape and Strides, parts 1-3

    Part 2 (/stride-guide-part-2/) covers transpose and C vs Fortran order; part 3 (/stride-guide-part-3/) covers as_strided. Compute each stride by hand before printing it.

  3. Read

    Rougier, chapter "Code vectorization": Uniform vectorization

    Do the Game of Life section. Skip temporal and spatial vectorization on the first pass.

  4. Do

    numpy-100 #1-40

    No hints. Mark each one that relies on strides, broadcasting or views.

  5. Read

    Edward Yang, PyTorch internals, first part (tensors, strides, storage, dispatch, extension points)

    The post is in two parts. Stop when it moves to working in the PyTorch codebase; the stride and storage diagrams are what you need here.

  6. Do

    Sasha Rush, Tensor Puzzles 1-10

    ones, sum, outer, diag, eye, triu, cumsum, diff, vstack, roll. One line under 80 columns each, using only arange, where, @, arithmetic, comparisons, indexing and earlier puzzles.

  7. Do

    Sasha Rush, Tensor Puzzles 11-21

    flip, compress, pad_to, sequence_mask, bincount, scatter_add, flatten, linspace, heaviside, repeat, bucketize.

  8. Do

    numpy-100 stride exercises: #75, #76, #81, #84, #87

    Sliding-window averages, shifted rows, contiguous 3x3 blocks and 4x4 block sums. Solve each with numpy.lib.stride_tricks.as_strided and write down the strides you passed.

Build

An NDArray class in pure Python over a flat list: shape, strides, offset; __getitem__ for ints and slices (views, no copy); reshape (view when contiguous, else copy), permute/transpose, expand (stride 0), broadcasting elementwise add/mul, sum(axis), and contiguous(). Tested against NumPy on random shapes.

Portfolio project: kiln v0.3: views without copying (a mini ShapeTracker)

kiln, the main project · v0.3 adds views (reshape, permute, expand, pad, shrink) without copying · builds on v0.2 · next: v0.4

Add a view system to kiln. Build a symbolic view system that composes reshape, permute, expand, pad, shrink and stride operations without touching data. It emits one index expression (a C string) mapping output index to input address, or reports that a copy is needed. This is the idea behind tinygrad's ShapeTracker, which you will meet again in the compiler modules. Property-test it against NumPy on random op chains.

Deliverables

  • repo with the view system, a C-expression emitter, and a randomized property test against NumPy
  • README showing example op chains, their emitted index expressions, and how many chains merge into one view vs need a copy
  • a 600–1200 word write-up explaining when two views can be merged and why this lets a compiler fuse movement ops for free

Rubric

Solid
Passes at least 10,000 random chains of up to 6 ops against NumPy; emitted C compiles and gives identical results.
Exceptional
Simplifies emitted index expressions (constant folding, removing mod/div when provably unneeded), supports masks for pad, and compares its design to tinygrad's ShapeTracker with references to specific code.

References: tinygrad v0.9.0, tinygrad/shape/shapetracker.py

Help

If you get stuck

  • Negative-step slices: the offset moves to the last element and the stride becomes negative. Test x[::-1] early.
  • Reshape after transpose: the result usually cannot be described with strides, so it must copy. Detect this by comparing the strides with those of a contiguous array of the same shape.
  • Broadcasting aligns shapes from the right. (3,) + (3,1) gives (3,3), not an error.
  • Tensor Puzzles forbid sum and most library functions. After puzzle 2, reduce by reusing your own sum (for example a @ ones).

Ready to move on when

  • Given a contiguous float32 array of shape (2,3,4), state its strides in bytes and the flat element index of [1,2,3].
  • Explain why transpose costs nothing but a reshape after it may need a copy.
  • Explain how expand is implemented with stride 0.
  • All 21 Tensor Puzzles pass.
  • Build a sliding-window view with as_strided and justify each stride.
