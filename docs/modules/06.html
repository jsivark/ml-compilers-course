06Tensors, broadcasting, strides

A tensor is a pointer, a shape and strides. Reshape, permute and expand are pure index arithmetic, which is exactly what you will compile in Module 22.

about 30–45 h · difficulty ●●●○○

After this module you can

  • After this module you can compute strides and offsets for any view (slice, transpose, expand) and predict when an operation copies.
  • After this module you can implement broadcasting from first principles and explain its rules.
  • After this module you can vectorize Python loops into array operations fluently.
  • After this module you can explain how PyTorch separates a tensor's storage from its view metadata.

Steps

Work through these in order. Each step points at one specific unit.

  1. Read

    Rougier, From Python to NumPy ch. 2: Anatomy of an array

    Memory layout, views vs copies, and the stride-based view examples. Run every snippet.

  2. Read

    Alex Riley, A Guide to NumPy Strides, parts 1-3

    Then stride-guide-part-2/ and part-3/. Compute the strides yourself before printing them.

  3. Read

    Rougier ch. 3: Code vectorization

    Focus on uniform vectorization (Game of Life); skip the temporal/spatial sections on first pass.

  4. Do

    numpy-100 #1-40

    Without looking at hints. Note every one that involves strides, broadcasting or views.

  5. Read

    Edward Yang, PyTorch internals (the Concepts section: tensors, strides, views, dispatch)

    Stop before the 'Mechanics' code tour if it gets heavy; the stride diagrams are the point.

  6. Do

    Sasha Rush, Tensor Puzzles: puzzles 1-10

    ones, sum, outer, diag, eye, triu, cumsum, diff, vstack, roll, using only arange, where and broadcasting.

  7. Do

    Sasha Rush, Tensor Puzzles: puzzles 11-21

    flip, compress, pad_to, sequence_mask, bincount, scatter_add, flatten, linspace, heaviside, repeat, bucketize. Try for shortest solutions.

  8. Do

    numpy-100 #41-70

    Especially the as_strided / sliding-window and broadcasting exercises.

  9. Read

    Maharshi Pandya, Tensors from Scratch part 1

    Same ideas in C; preview of what your compiler generates.

Build

An NDArray class in pure Python over a flat list: shape, strides, offset; __getitem__ for ints and slices (views, no copy); reshape (view when contiguous, else copy), permute/transpose, expand (stride 0), broadcasting elementwise add/mul, sum(axis), and contiguous(). Tested against NumPy on random shapes.

Portfolio project: A view-tracking shape tracker (a mini ShapeTracker)

Build a symbolic view system that composes reshape, permute, expand, pad, shrink and stride operations without touching data, and emits a single index expression (as a string of C) mapping output index to input address, or reports that a copy is needed. This is the core idea behind tinygrad's ShapeTracker, which you will meet again in the compiler modules. Property-test it against NumPy on thousands of random op chains.

Deliverables

  • repo with the view system, a C-expression emitter, and a randomized property test against NumPy
  • README showing example op chains, their emitted index expressions, and how many chains merge into one view vs need a copy
  • a 600–1200 word write-up explaining when two views can be merged and why this lets a compiler fuse movement ops for free

Rubric

Solid
Passes at least 10,000 random chains of up to 6 ops against NumPy; emitted C compiles and gives identical results.
Exceptional
Simplifies emitted index expressions (constant folding, removing mod/div when provably unneeded), supports masks for pad, and compares its design to tinygrad's ShapeTracker with specific code references.

References: tinygrad (see tinygrad/shape)

If you get stuck

  • Negative-step slices: the offset moves to the last element and the stride becomes negative; test x[::-1] early.
  • reshape after transpose: the result is not expressible with strides, so it must copy; check contiguity by comparing strides with the strides a contiguous array would have.
  • Broadcasting aligns shapes from the right, not the left; (3,) + (3,1) gives (3,3), not an error.
  • Tensor Puzzles forbid loops and most functions; use arange, comparisons and broadcasting (where to index, sum to reduce).

Ready to move on when

  • Given shape (2,3,4) contiguous, state strides and the flat index of [1,2,3].
  • Explain why transpose is free but a subsequent reshape may need a copy.
  • Explain how expand/broadcast is implemented with stride 0.
  • All 21 Tensor Puzzles pass.
  • Implement a sliding-window view with as_strided and explain the strides.
