How to use this course
  • Go in order. Each module assumes the ones before it. If you already know a topic, do its Build step anyway. If it's easy, skip ahead.
  • No deadlines. Move on when the build works and you can answer every “ready to move on when” question without notes.
  • Get the code. The assignments, tests and this site's source are on GitHub: github.com/jsivark/ml-compilers-course.
  • Build one system, plus focused projects. Your main project, kiln, grows from a C tensor core in Module 1 to a compiler that trains a GPT on your GPU in Module 38. Each version works on its own. Skill projects along the way teach what kiln does not cover. See the portfolio.
  • Effort estimates are honest, not deadlines. Hard modules take longer. Being stuck is normal, and every module has an “if you get stuck” section.
  • Write the code yourself. Use AI to explain things and to debug, not to write your compiler. The real course has the same rule.
